# SilverRingo_Digital_Literacy_Assistant
AI 및 디지털 기기 사용에 대한 경험 및 지식이 없는 디지털 취약 계층을 대상으로 한 어플리케이션입니다. 해당 계층에게 적합한 마이크로러닝 모듈을 제공하고 UI 실습 및 영상을 통한 다각화된 실습을 통해 접근성을 향상시키고 적응하도록 돕습니다.
