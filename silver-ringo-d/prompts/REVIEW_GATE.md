# 모듈 완료 후 검토 게이트 (Codex용 또는 사람이 확인)

1. 어떤 파일을 변경했나? `git diff --stat`, `git diff` 요약.
2. 지정한 Mxx 설계서의 수락 기준이 모두 충족됐나? 빠진 조건을 표로 작성.
3. 정상/경계/비정상 입력 테스트를 실제 실행했나? 결과와 실행 명령.
4. 타 팀 브랜치, `main`, CI/Tester 기존 코드를 건드리지 않았나?
5. 현재 구현 사실과 아이디어, 실제 연동 가능과 미연동 상태를 혼동하지 않았나?
6. 비밀키/민감정보/생성된 cache 파일을 commit 대상에 넣지 않았나?
7. 다음 모듈이 요구하는 공개 인터페이스와 변경사항은 무엇인가?
8. 외부 API를 실호출했다면 횟수, 계정/키에 대한 노출 유무, 실제 한도 확인 결과를 보고.

인간 검토가 끝나기 전 자동 commit/merge/push 금지.
