========================================================================
   SilverLingo(실버링고) 스마트폰 실기기 설치 및 시연 가이드
========================================================================

어르신을 위한 1:1 서드파티 플로팅 오버레이 동행 도우미 'SilverLingo'의
실제 안드로이드 스마트폰(삼성 갤럭시 등) 설치 및 시연 안내서입니다.


------------------------------------------------------------------------
[1] 스마트폰에 설치하는 2가지 방법 (편한 방법을 선택하세요)
------------------------------------------------------------------------

■ 방법 A. 스마트폰으로 바로 보내서 설치 (추천: 선 연결 없이 무선으로 간편)
  1. 본 폴더에 있는 'SilverLingo_스마트폰_시연용.apk' 파일(약 17MB)을
     카카오톡(나와의 채팅), 이메일, 네이버 MYBOX, 구글 드라이브 등으로 스마트폰에 보냅니다.
  2. 스마트폰에서 전송받은 APK 파일을 터치하여 다운로드 및 실행합니다.
  3. "보안상의 이유로 이 출처의 알 수 없는 앱을 설치할 수 없습니다" 팝업이 뜨면:
     -> [설정] 터치 -> "이 출처의 앱 허용" 스위치를 켭니다.
  4. [설치] 버튼을 누르면 스마트폰에 즉시 설치 완료됩니다!

■ 방법 B. PC와 USB 케이블로 연결하여 1초 만에 자동 설치
  1. 스마트폰과 PC를 USB 케이블로 연결합니다.
  2. 스마트폰 [설정] -> [개발자 옵션] -> [USB 디버깅]을 켭니다.
     (개발자 옵션이 보이지 않는 경우: [설정] -> [휴대전화 정보] -> [소프트웨어 정보] -> '빌드번호'를 연속 7번 터치)
  3. 스마트폰 화면에 "USB 디버깅을 허용하시겠습니까?"가 뜨면 '이 컴퓨터에서 항상 허용' 체크 후 [허용] 터치.
  4. 본 폴더의 '스마트폰_원클릭_설치.bat'을 더블 클릭하면 SilverLingo 앱과 똑닥 분할 패키지가 자동으로 설치되고 권한 설정 화면까지 스마트폰에 자동으로 띄워줍니다.


------------------------------------------------------------------------
[2] 스마트폰 필수 권한 2가지 켜기 (최초 1회 필수)
------------------------------------------------------------------------
SilverLingo는 다른 앱(카카오 T, 코레일, 인터넷 브라우저 등) 화면 위에서
둥둥 떠다니며 버튼을 짚어주는 "서드파티 플로팅 오버레이" 방식이므로
다음 2가지 권한이 필요합니다. (앱 실행 시 대시보드에서 버튼을 눌러 바로 켤 수도 있습니다)

  1. 다른 앱 위에 표시 (화면 오버레이 권한)
     - 스마트폰 [설정] -> [애플리케이션] -> 우측 상단 점 3개 -> [특별한 접근] -> [다른 앱 위에 표시]
       (또는 앱 첫 화면의 "화면 위에 그리기 권한" 버튼 터치)
     - 목록에서 [SilverLingo]를 찾아 스위치를 켭니다 (파란색).

  2. 접근성 서비스 (화면 버튼 자동 감지 및 노란색 포커스 링 표시)
     - 스마트폰 [설정] -> [접근성] -> [설치된 앱] (또는 설치된 서비스)
       (또는 앱 첫 화면의 "접근성 서비스 권한" 버튼 터치)
     - [SilverLingo 도우미]를 선택한 후 스위치를 [사용 중]으로 켭니다.
     - "SilverLingo 도우미에 휴대전화의 전체 제어 권한을 허용하시겠습니까?" 경고창에서 [허용]을 누릅니다.


------------------------------------------------------------------------
[3] 추천 시연 시나리오 (발표 및 데모)
------------------------------------------------------------------------

★ 시나리오 1. 카카오 T 어르신 안심 택시 호출 (핵심 추천 ⭐)
  - SilverLingo 메인 화면에서 [🚕 안심 택시 부르기] 카드를 터치합니다.
  - 다이얼로그에서 노란색 [🎬 안심 발표 시연 모드 (로그인 불필요)] 버튼을 누릅니다.
  - 실제 카카오 T와 완전히 동일한 환경에서 계정 로그인/실제 결제 리스크 없이:
    1단계: [택시] 아이콘 위에 반짝이는 포커스 링과 말풍선, 0.88배속 음성 안내 확인
    2단계: [서울아산병원 (송파구)] 원터치 목적지 선택
    3단계: 카드 등록 없는 [일반호출 / 기사님 직접 결제] 선택
    4단계: 배차 완료 팝업 및 음성 축하 안내까지 매끄럽게 시연 가능!
  - (스마트폰에 실제 카카오 T 앱이 깔려있다면 [📱 공식 앱으로 열기]를 눌러 실제 앱 위에서 작동하는 모습도 시연 가능합니다)

★ 시나리오 2. 코레일 기차표 예매
  - SilverLingo 메인 화면에서 [🚆 기차표 예매 (코레일)] 카드를 터치합니다.
  - 인앱 브라우저로 실제 코레일 공식 웹사이트가 전체화면으로 열리며:
    1단계: 승차권 조회 버튼 자동 포커스 링 & "여기를 누르세요" 말풍선
    2단계: 10:30 KTX 열차 예매하기 버튼 자동 추적
    3단계: 경로 우대(30%) 안내 및 카카오톡 간편인증 연동까지 1:1 동행 가이드 제공!

★ 시나리오 3. 병원 안심 당일 접수 (똑닥 DDocDoc)
  - SilverLingo 메인 화면에서 [🏥 병원 안심 당일 접수] 카드를 터치합니다.
  - [🌐 인터넷 화면으로 열기 (웹 동행)]을 누르면 실제 최신 똑닥 모바일 서비스(`ddocdoc.com`)가 열리며:
    1단계: 병원 찾기 및 진료과 선택
    2단계: [진료 접수하기] 버튼 하이라이트
    3단계: [본인] 선택 ➔ 접수 신청 완료까지 실시간 오버레이 가이드가 부드럽게 작동합니다.


------------------------------------------------------------------------
[4] SilverLingo만의 핵심 차별점 및 기술 포인트
------------------------------------------------------------------------
1. 온디바이스 제로-서버(Zero-Knowledge) 원칙
   - 개인정보(이름, 주소 등)는 서버로 전송하지 않고 오직 스마트폰 내부 암호화 저장소에만 보관하여 개인정보보호법 100% 준수 (즉시 상용화 가능).
2. 매크로 차단 없는 안심 동행
   - 코레일 등 매크로 탐지 사이트에 걸리지 않도록 대리 클릭을 하지 않고 어르신의 직접 터치를 유도.
3. 반투명 글래스모피즘 & 원터치 비키기
   - 말풍선이 화면이나 버튼을 가리지 않도록 85% 반투명 블러 디자인 적용 및 [↕ 위치 비키기] 원터치 지원.
4. 어르신 맞춤형 0.88배속 친절한 음성 동행(TTS)
   - 귀가 어두우신 어르신도 놓치지 않고 따라오실 수 있는 또박또박한 음성 안내 제공.
