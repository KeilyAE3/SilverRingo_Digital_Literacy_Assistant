# Agent Commit Report Template

아래 형식으로 각 팀원이 에이전트 기반 작업 보고서를 커밋에 포함합니다.

## 1) 기본 정보
- 날짜: YYYY-MM-DD
- 팀원: member-1 | member-2 | member-3 | member-4
- 에이전트/모델:
- 관련 이슈/작업 링크:
- 관련 커밋 SHA:

## 2) 작업 목적
- 이번 커밋에서 해결하려는 문제/가설

## 3) 적용 원리 및 접근 방식
- 왜 이 방법을 선택했는지
- 핵심 설계 포인트

## 4) 변경 사항 요약
- 파일/기능 단위 요약

## 5) 검증
- 테스트/수동 검증 결과
- 리스크 및 대응

## 6) 다음 작업
- 후속 액션 아이템
- 협업이 필요한 항목
